the rest period / how-to

why ur "last set" is never the last set

by harry
stand-in photo

You said "last set." Then you did another one. Then one more, because the first two didn't count. We've all been there.

"Last set" is a feeling, not a plan. It shows up when you're tired, and it leaves the moment someone walks past.

the fix

Decide your sets before you start. Three sets, written down, done. If the box counts a fourth, you'll see it in the report, and next time you can choose on purpose.

one more thing

An extra set isn't a crime. Not knowing you did it is the problem, because next week's plan gets built on a guess.

Count hard, Harry
